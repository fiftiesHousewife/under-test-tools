## The first release

under-test-tools does the mechanical steps of [under-test](https://github.com/fiftiesHousewife/under-test)'s journey,
one sub-command each, in one jar that runs on Java 17 or later.

* **`meaningless-and-unreliable`** lists a repo's tests, runs PMD with under-test's rules for meaningless and
  unreliable tests, gives each hit to its test, and writes the two lists to `testing/tests.yaml` and their summaries
  to `testing/assessment.yaml`.
* **`repair-orders`** joins `testing/external-calls.json`, `testing/tests.yaml` and
  `testing/external-systems.calm.json` into `testing/repair-orders.json`: a work order for each external system, for
  the repair skill (schema `repair-orders/1`).

It reads a repo's files, writes only under its `testing/` folder, and runs none of the repo's code.
